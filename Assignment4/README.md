# Контрольные вопросы - ответы

**1. В чём заключается отличие гибридных вычислений от вычислений только на
CPU или только на GPU?**

Гибридные вычисления используют одновременно CPU и GPU, позволяя комбинировать их ресурсы для ускорения обработки. CPU- или GPU-вычисления используют только один тип устройства.

**2. Для каких типов задач целесообразно распределять вычисления между CPU и
GPU?**

Для задач с большими объёмами данных, которые можно параллельно разделить. CPU лучше справляется с ветвлениями и последовательной логикой, GPU — с массивными параллельными вычислениями.

**3. В чём разница между синхронной и асинхронной передачей данных между CPU
и GPU?**

- _Синхронная_: CPU ждёт окончания передачи данных перед продолжением работы.

- _Асинхронная_: CPU продолжает выполнение, пока данные передаются на GPU.

**4. Почему асинхронная передача данных может повысить производительность
программы?**

Позволяет накладывать передачу данных и вычисления, уменьшая простой ресурсов.

**5. Какие основные функции MPI используются для распределения и сбора данных
между процессами?**

```MPI_Scatter``` – распределение массива между процессами.

```MPI_Gather / MPI_Reduce``` – сбор результатов с процессов.

**6. Как количество процессов MPI влияет на время выполнения программы и
почему?**

Увеличение числа процессов может ускорять вычисления, но накладные расходы на коммуникацию растут. Оптимум зависит от размера данных.

**7. Какие факторы ограничивают масштабируемость распределённых
параллельных программ?**

- Сетевые задержки и пропускная способность.

- Накладные расходы на синхронизацию.

- Неравномерное распределение данных или вычислительной нагрузки.

**8. В каких случаях использование распределённых вычислений оправдано, а в
каких — неэффективно?**

_Оправдано_: большие массивы данных, высокие вычислительные нагрузки, возможность параллельной работы.

_Неэффективно_: маленькие массивы, задачи с малым объёмом вычислений и высокой частотой коммуникации.
