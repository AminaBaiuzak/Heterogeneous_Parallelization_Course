В рамках практической работы была выполнена разработка кросс-платформенного приложения с использованием OpenCL для параллельного выполнения вычислений на CPU и GPU. Работа была разделена на две основные задачи:

**Задача 1 — Параллельное сложение массивов**

- Были созданы два массива A и B размером N элементов.

- Реализовано ядро OpenCL (vector_add.cl), которое выполняет поэлементное сложение массивов.

- На хосте создан контекст и очередь команд для каждого устройства (CPU и GPU).

- Буферы данных передавались в ядро, запускалось параллельное вычисление, результаты считывались обратно.

- Результаты работы проверялись, а время выполнения фиксировалось для CPU и GPU.

- Полученные результаты продемонстрировали ускорение на GPU по сравнению с CPU.

**Задача 2 — Параллельное умножение матриц**

- Созданы матрицы A[N×M] и B[M×K], рассчитана результирующая матрица C[N×K].

- Разработано ядро OpenCL (matrix_mul.cl), где каждый поток вычисляет один элемент результирующей матрицы, что обеспечивает параллельность вычислений.

- Результаты параллельного умножения сравнивались с последовательной реализацией на CPU для проверки корректности.

- Время выполнения фиксировалось для CPU и GPU, показав ускорение на GPU за счет параллельной обработки.

**Общие результаты и выводы:**

На практике были изучены основные этапы работы с OpenCL: выбор платформы и устройства, создание контекста и очереди команд, компиляция и запуск ядра, работа с буферами и считывание результатов. 
Показано, что параллельная обработка на GPU значительно ускоряет выполнение ресурсоёмких вычислений, таких как сложение больших массивов и умножение матриц.
Блок-схемы и графики сравнения времени выполнения на CPU и GPU позволяют визуально продемонстрировать преимущества параллельных вычислений.

# Контрольные вопросы - ответы

**1. Какие основные типы памяти используются в OpenCL?**

В OpenCL есть несколько типов памяти, каждый с разным временем доступа и областью видимости:

1.1. Global memory (глобальная память). Доступна всем ядрам (work-items) и устройствам на платформе.
Медленная по сравнению с другими типами. Используется для передачи данных между хостом и устройством.

1.2. Local memory (локальная память).
Общая память для всех work-items внутри одной рабочей группы (work-group). Быстрее глобальной, но ограничена по объему. Используется для обмена данными между потоками одной группы и для оптимизации.

1.3. Private memory (приватная память).
Память, доступная только отдельному work-item. Обычно это регистры процессора/ядра. Самая быстрая, но объём ограничен.

1.4. Constant memory (константная память).
Для данных, которые не меняются во время выполнения ядра.Быстро кэшируется на устройстве, доступна всем work-items.

**2. Как настроить глобальную и локальную рабочую группу?**

В OpenCL вычислительная работа распределяется на work-items и work-groups:

- Глобальная рабочая группа (global work size). Определяет общее количество потоков для выполнения ядра.

Например, для сложения массивов из N элементов:
```C++
size_t globalSize = N;
clEnqueueNDRangeKernel(queue, kernel, 1, nullptr, &globalSize, nullptr, 0, nullptr, nullptr);
```
- Локальная рабочая группа (local work size)

Определяет количество потоков внутри одной группы. Задает, как work-items распределяются внутри группы для оптимизации доступа к локальной памяти.

Пример: 16 потоков на группу:

```C++
size_t localSize = 16;
clEnqueueNDRangeKernel(queue, kernel, 1, nullptr, &globalSize, &localSize, 0, nullptr, nullptr);
```

**3. Чем отличается OpenCL от CUDA?**

| Характеристика | OpenCL | CUDA |
| :--- | :----: | :----: |
| Поддержка платформ | Кроссплатформенная (CPU, GPU, FPGA) | Только NVIDIA GPU |
| Поддержка платформ | C-подобный с расширениями | C++-подобный с расширениями |
| Портируемость | Высокая (работает на разных устройствах) | Ограничена картами NVIDIA |
| Сообщество и примеры | Меньше библиотек, сложнее | Огромная экосистема, много библиотек |
| Использование | Универсально для CPU/GPU | Только для NVIDIA GPU |


**4. Какие преимущества дает использование OpenCL?**

4.1 Кроссплатформенность. Код работает на GPU, CPU, FPGA и других ускорителях.

4.2. Параллельное вычисление. Позволяет использовать тысячи потоков одновременно для ускорения обработки данных.

4.3. Оптимизация под разные устройства. Можно управлять рабочими группами, памятью и потоками, чтобы использовать ресурсы максимально эффективно.

4.4. Универсальность. Подходит не только для графики (как CUDA), но и для вычислительных задач: математика, физика, машинное обучение.
