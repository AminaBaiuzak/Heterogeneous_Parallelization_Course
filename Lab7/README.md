# Практическая работа №7
**Цель работы:** Изучение и реализация параллельных алгоритмов редукции
и сканирования (префиксной суммы) на GPU с использованием технологии CUDA,
а также анализ и оптимизация их производительности.

**Задачи работы:**

1. Реализовать алгоритм редукции для вычисления суммы элементов массива на GPU.
2. Реализовать алгоритм сканирования (префиксной суммы) на GPU.
3. Провести анализ производительности реализованных алгоритмов.
4. Оптимизировать код с использованием различных типов памяти CUDA.
-----------------------------------------------------
**Теоретическая часть**

**_1. Редукция_**

Редукция — это параллельная операция, которая сводит массив данных к одному значению (например, сумма, минимум или максимум).
На GPU редукция реализуется с использованием:
 
- иерархии потоков,
- разделяемой памяти,
- поэтапного уменьшения числа активных элементов.

Редукция широко используется в задачах анализа данных, машинного обучения и обработки изображений.

**_2. Сканирование (префиксная сумма)_**

Сканирование — это операция, при которой для каждого элемента массива вычисляется накопленная сумма предыдущих элементов.
```bash
Вход:  [1, 2, 3, 4]
Выход: [1, 3, 6, 10]
```

Сканирование применяется в алгоритмах сортировки, построении гистограмм, сжатии данных и графовых алгоритмах.

**_3. Типы памяти в CUDA_**

В работе используются следующие типы памяти CUDA:

- Глобальная память — основная память GPU, доступная всем потокам, но с высокой задержкой.
- Разделяемая память (Shared Memory) — быстрая память, общая для потоков одного блока.
- Локальная память — память, используемая отдельным потоком (часто реализуется через регистры).

Оптимизация достигается за счёт активного использования разделяемой памяти.

**Практическая часть**

**_Реализация редукции_**

- Реализовано CUDA-ядро для вычисления суммы элементов массива.

- Используется разделяемая память для уменьшения обращений к глобальной памяти.

- Реализованы дополнительные варианты редукции для поиска минимума и максимума.

- Корректность проверяется сравнением с CPU-реализацией.

**_Реализация префиксной суммы_**
- Реализован алгоритм Blelloch Scan (exclusive scan).

- Сканирование выполняется в несколько этапов:

  1. Сканирование внутри блоков.
  2. Сканирование сумм блоков.
  3. Добавление смещений к каждому блоку.

- Используется разделяемая память.

- Корректность проверяется сравнением с CPU-версией.

**_Задание 3: Анализ производительности_**
- Проведены замеры времени выполнения:

  - редукции,

  - сканирования

- Использованы массивы размером:

  - 1024 элементов,

  - 1 000 000 элементов,

  - 10 000 000 элементов.

- Выполнено сравнение производительности CPU и GPU.

- Исследовано влияние размера блока (64, 128, 256, 512).

**Результаты**

- GPU-реализация показывает значительный прирост производительности по сравнению с CPU при больших размерах массивов.

- Использование разделяемой памяти существенно снижает время выполнения.

- Оптимальный размер блока зависит от архитектуры GPU, но чаще всего эффективны блоки размером 256 потоков.

# Контрольные вопросы и ответы
**1. В чём разница между редукцией и сканированием?**

Редукция сводит массив к одному значению (например, сумма),
сканирование вычисляет накопленный результат для каждого элемента массива.

**2. Какие типы памяти CUDA используются для оптимизации редукции и сканирования?**

Для оптимизации используются:

- разделяемая память (основная оптимизация),

- глобальная память (для хранения входных и выходных данных),

- регистры (для временных вычислений внутри потоков).

**3. Как можно оптимизировать префиксную сумму на GPU?**

Основные способы оптимизации:

- использование алгоритма Blelloch Scan,

- применение разделяемой памяти,

- уменьшение числа обращений к глобальной памяти,

- выбор оптимального размера блока.

**4. Приведите пример задачи, где применяется сканирование.**

Сканирование применяется в:

- параллельной сортировке,

- построении гистограмм,

- алгоритмах сжатия данных,

- обработке графов,

- компьютерном зрении.
