# Контрольные вопросы - ответы

**1. Какие преимущества предоставляют гибридные вычисления?**

Гибридные вычисления — это подход, при котором задачи распределяются между CPU и GPU для достижения максимальной производительности. Основные преимущества:

- Максимальное использование ресурсов системы: CPU выполняет последовательные или управляющие задачи, а GPU — массивные параллельные вычисления.

- Сокращение времени выполнения: благодаря параллельной обработке больших массивов данных на GPU и одновременной обработке на CPU.

- Гибкость распределения нагрузки: можно оптимизировать, какая часть данных обрабатывается на CPU, а какая — на GPU, в зависимости от их характеристик.

- Уменьшение узких мест: CPU и GPU могут работать одновременно, пока одни ядра ждут передачи данных, другие уже выполняют вычисления.

**2. Как минимизировать накладные расходы при передаче данных между CPU и GPU?**

- Минимизировать количество копирований: переносить данные на GPU один раз для больших блоков, а не поэлементно.

- Использовать асинхронные операции и streams: CPU может выполнять работу параллельно с передачей данных на GPU.

- Использовать pinned memory (page-locked memory): ускоряет передачу данных по шине PCIe.

- Обрабатывать данные частями, но так, чтобы размер блока был оптимальным: слишком маленькие блоки приводят к тому, что накладные расходы на копирование превышают пользу от параллельной обработки.

**3. Какие задачи лучше выполнять на CPU, а какие — на GPU?**

_CPU:_

1. Последовательные задачи или алгоритмы с большим количеством ветвлений.

2. Управляющие и координационные задачи.

3. Малые объёмы данных, где накладные расходы на передачу на GPU будут выше, чем ускорение.

_GPU:_

1. Массовые параллельные вычисления, одинаковые операции на большом количестве данных (например, обработка массивов, матриц).

2. Алгоритмы, где количество операций на один элемент велико, а управление минимально.

**4. Как можно улучшить производительность гибридного приложения?**

- Оптимизация работы GPU: использовать больше потоков, оптимизировать доступ к памяти (shared memory, coalesced memory access).

- Использование pinned memory для ускорения копирования данных.

- Асинхронные передачи и streams: CPU может работать параллельно с GPU.

- Балансировка нагрузки: правильное распределение данных между CPU и GPU в зависимости от их производительности.

- Сведение к минимуму операций между CPU и GPU: обрабатывать максимально большие блоки за раз.

- Профилирование и оптимизация критических участков: использовать инструменты профилирования CUDA для поиска узких мест.
